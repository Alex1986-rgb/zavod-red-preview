# INDEX — оглавление вики конкурентной разведки

Читай этот файл первым. Дальше открывай только нужные листы (гигиена контекста).

## entities/ — факты (вход)
- [[company]] — кто мы: юрлицо, гео, суть, каналы.
- [[products]] — продукция ZR: редукторы, мотор-редукторы, подбор, импортозамещение.
- [[positioning]] — текущее позиционирование, tone of voice, правила по ценам.
- [[audience]] — целевая аудитория (сегменты, боли) — обогащается в Stage 1.
- [[site]] — сайт zavod-red.ru: ключевые страницы, воронка, точки заявки.

## concepts/ — выводы агентов (пишутся системой)
Stage 1 → analysis-*, Stage 2 → audit/positioning/blind-spots, Stage 3 см. deliverables/.
(изначально пусто — заполняется при запуске стадий)

## Правила
- Факты — только в `entities/`, атомарно. Выводы — только в `concepts/`.
- Каждый агент дописывает свой файл и добавляет строку в [[log]].
- Итоговые материалы — в `../deliverables/`.
