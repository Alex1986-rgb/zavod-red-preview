# Целевая аудитория (каркас — обогащается в Stage 1)

Гипотезы сегментов (уточнить агентом `intel-analyst-audience`):
- **Снабженцы / отделы закупок** промпредприятий — ищут замену импортному редуктору по ТТХ и срокам.
- **Инженеры-механики / гл. механик** — подбор привода по моменту/оборотам/присоединительным размерам.
- **Проектные организации** — подбор под новое оборудование.
- **Сервис / ремонт** — срочная замена вышедшего из строя узла.

Ключевые боли (проверить): сроки поставки, совместимость без переделки, цена без посредника, доверие к производителю.
