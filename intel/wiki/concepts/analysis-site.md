# Анализ сайта zavod-red.ru (Stage 1 — только факты)

Источник: боевой https://zavod-red.ru недоступен из среды (WebFetch заблокирован сетевой политикой). Разбор по локальным исходникам репозитория: `index.html`, `podbor.html`, `catalog/`, `ceny.html`, `assets/modal.js`. Тёмная тема по умолчанию — light (`zr_theme`=light), есть переключатель тёмная/светлая.

## Шапка (header, sticky)
- Верхняя полоса: «Собственное производство · отгрузка по всей России» + почта `zr@zavod-red.ru` + телефон `+7 (904) 953-41-02`.
- Логотип «Завод Редукторов», кнопка «Каталог», строка поиска (placeholder «Поиск по 85 000+ позициям: ZR 979, SEW R107, NMRV 050…», отправка на `/podbor`), иконки Кабинет и Корзина, переключатель темы, CTA-кнопка «Получить расчёт» (→ модалка `#zayavka`).
- Меню: Каталог редукторов, Подбор, Мотор-редукторы ZR, Цены, Производителям, Импортозамещение, Блог, «О заводе» (выпадающее: фото производства / люди / сертификаты / о заводе), Контакты. Второй телефон в меню `+7 (495) 151-41-02`.

- Раздел «Цена от производителя» (`#ceny-teaser`): H2 «Понижающие мотор-редукторы — по запросу». 4 карточки типов (Червячный / Соосно-цилиндрический / Цилиндро-конический / Плоский цилиндрический) — у всех цена «по запросу». Кнопки «Все цены ZR · ПР · МР» (→ `/ceny`) и «Получить прайс и расчёт».
- Явных чисел-цен и фиксированных пакетов на главной нет — везде «по запросу» / «экономия ~40%» / «в разы дороже». Отдельная страница `/ceny` (`ceny.html`).

## Форма заявки и путь к ней
- Единая точка заявки — **модальное окно** (`assets/modal.js`), триггер `[data-zayavka]` / ссылки `#zayavka`. Открывается кнопками «Получить расчёт» по всему сайту (hero, header, ceny, situation, oem, compare, final-cta, мобильная нижняя CTA-полоса, подбор).
- Заголовок модалки: «Получите расчёт стоимости». Интро: «Заполните форму — инженер свяжется в течение 15 минут, рассчитает подбор и пришлёт коммерческое предложение».
- Поля: select «Какой редуктор нужен?» (9 вариантов), Имя (обяз.), Телефон (обяз.), Почта (необяз.), файл (фото шильда/чертёж/спецификация, JPG/PDF/DOC/XLS/DWG до 10 МБ), textarea «опишите задачу», чекбокс согласия на обработку ПДн. Honeypot `work_email`.
- Отправка: POST на `/api/feedback.php`. При успехе — цель Метрики `ym reachGoal 'zayavka'`.
- Дополнительный путь: калькулятор `/podbor` + промо-блок «Не знаете параметры? Подобрать по фото шильдика» (тоже открывает модалку).
- Форма поиска в шапке (GET `/podbor`).

## Финальный экран и подвал
- Финальный CTA (`#contacts`): H2 «Получите подбор и цену сегодня» + «инженер ответит за 15 минут» + кнопки «Получить расчёт» / «Подбор по параметрам».
- Подвал: 4 колонки (Каталог / Разделы / Компания), телефоны, почта, реквизиты, ссылки на политику конфиденциальности, соглашение, карту сайта.

## Чего на главной нет (констатация)
- Нет опубликованных числовых цен и фиксированных тарифных пакетов (везде «по запросу»).
- Нет онлайн-оплаты/корзинного оформления на главной (иконка корзины/кабинет ведут в отдельные разделы `/cart`, `/cabinet`).
- Отзывы обезличены (без имён/компаний/скринов), aggregateRating только в разметке (6 отзывов).
- Кейсы вынесены в отдельный раздел `/cases/` (на главной блока с карточками кейсов не зафиксировано).
