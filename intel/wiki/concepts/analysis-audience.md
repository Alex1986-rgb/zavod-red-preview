# Анализ целевой аудитории — «Завод Редукторов» (Stage 1)

Сегменты, боли/JTBD, критерии выбора и типичные формулировки запросов покупателей
промышленных редукторов/мотор-редукторов и импортозамещения приводов в РФ.

Пометки: **[ФАКТ]** — подтверждено внешним источником (ссылка); **[ГИПОТЕЗА]** — рабочее
предположение (нет данных по трафику/заявкам самого Завода — см. [[audience]], [[log]]).

---

## 1. Сегменты ЦА

- **Снабженцы / отделы закупок промпредприятий** **[ГИПОТЕЗА]**
  Ищут замену импортному редуктору по ТТХ, срокам, цене; часто работают через тендер/ТЗ.
  Мотив закупки — не бренд, а соответствие параметрам + срок поставки. Косвенно подтверждается тем,
  что поставщики строят предложение вокруг «сокращения срока поставки до 2 недель вместо 4–6» **[ФАКТ]**
  ([reductory74](https://reductory74.ru/kompaniya/news/analogi-reduktorov-sew/)).

- **Инженеры-механики / главный механик / гл. энергетик** **[ГИПОТЕЗА, косвенно ФАКТ]**
  Подбирают привод по расчёту: момент, обороты, передаточное число, монтажное исполнение,
  присоединительные/габаритные размеры. Логика подбора «от параметров, а не от бренда» подтверждена **[ФАКТ]**
  ([reductory74 — подбор](https://reductory74.ru/kompaniya/news/podbor-motor-reduktora-raschyet-vybor-tipa-i-montazhnogo-ispolneniya/)).

- **Проектные / инжиниринговые организации** **[ГИПОТЕЗА]**
  Подбор привода под новое оборудование на стадии проектирования; важна документация,
  каталожные обозначения, взаимозаменяемость по типоразмерам.

- **Сервис / ремонт / эксплуатация** **[ГИПОТЕЗА, косвенно ФАКТ]**
  Срочная замена вышедшего из строя узла: износ подшипников/шестерён/вала-шестерни;
  «шестерни и подшипники ремонту не подлежат, подбираются по идентичности размеров» **[ФАКТ]**
  ([reductor58 — ремонт](https://reductor58.ru/news/poleznaya-informatsiya/diagnostika-i-remont-chervyachnogo-reduktora/)).
  Для этого сегмента критичны наличие на складе и точное совпадение присоединительных размеров.

## 3. Критерии выбора (в порядке значимости — гипотеза по приоритету)

1. **Совместимость** — передаточное число, крутящий момент, монтажное исполнение, присоединительные
   размеры (диаметр/длина вала, фланец, монтажные отверстия). **[ФАКТ]**
   ([tehprivod — расчёт](https://tehprivod.ru/raschet-reduktora/), [reductor58](https://reductor58.ru/news/poleznaya-informatsiya/vybor-i-raschet-motor-reduktora/)).
2. **Срок поставки / наличие на складе** — часто решающий при аварийной замене. **[ФАКТ]**
   ([reductory74](https://reductory74.ru/kompaniya/news/analogi-reduktorov-sew/)).
3. **Цена без переплаты за бренд / «от производителя»**. **[ФАКТ]**
   ([rusautomation](https://rusautomation.ru/articles/alternativnaya_zamena_motor_reduktora_platit_za_brend_ili_nayti_zamenu_13699/)).
4. **Надёжность / ресурс / сервис-фактор** — проверка допустимых нагрузок на вал, теплового запаса. **[ФАКТ]**
   ([reductory74 — подбор](https://reductory74.ru/kompaniya/news/podbor-motor-reduktora-raschyet-vybor-tipa-i-montazhnogo-ispolneniya/)).
5. **Доверие к поставщику** (производитель, гарантия, наличие инженерного подбора). **[ГИПОТЕЗА]**.
6. **Формальные требования тендера** (новый товар, гарантия, монтаж/пусконаладка). **[ФАКТ, для сегмента закупок]**.

> Согласуется с позиционированием Завода «от производителя»: цена без посредников + инженерный подбор
> + замена импорта без переделки (см. [[analysis-company]]).

## 4. Типичные формулировки запросов

**Замена/аналог (снабженец, механик)** — подтверждённый паттерн формулировок в выдаче **[ФАКТ]**:
- «аналог редуктора SEW / NORD / Bonfiglioli / Motovario / Rossi»
- «отечественный аналог мотор-редуктора», «российский аналог SEW-Eurodrive»
- «замена импортного привода», «импортозамещение редукторов»
- «мотор-редуктор в наличии с доставкой»

**Подбор по параметрам (инженер)** **[ФАКТ]**:
- «подбор мотор-редуктора / расчёт редуктора»
- «передаточное число редуктора как посчитать»
- «типоразмеры / габариты мотор-редуктора», «присоединительные размеры редуктора»
- «червячный или цилиндрический редуктор — что выбрать»

**Ремонт/срочная замена (сервис)** **[ФАКТ]**:
- «ремонт / диагностика червячного (цилиндрического) редуктора»
- «замена подшипников / вала-шестерни редуктора»
- по обозначениям: серии **NMRV, Ч-100 / Ч-125 / Ч-160, DRV** и т.п.

**Закупка/тендер (отдел закупок)** **[ФАКТ]**:
- «редукторы тендер / госзакупки», «ТЗ на поставку редуктора»
- запросы на характеристики + сроки + гарантию под 44-ФЗ / 223-ФЗ.

**Гипотезы по формулировкам, не проверенные напрямую** **[ГИПОТЕЗА]**:
- «купить редуктор от производителя», «редуктор цена по запросу»,
  «редуктор без переделки под старое крепление», «кто производит редукторы в России».

## 5. Выводы для стратегии (передать Stage 2/3)

- Основной «вход» — **не бренд, а параметр/боль**: аналог конкретного импортного бренда ИЛИ подбор по
  моменту/оборотам/размерам. Это ложится на калькулятор `podbor` и карточки `brands/` **[связка ФАКТ+продукт]**.
- Два скоростных сегмента с разной срочностью: **аварийный сервис** (решает наличие+совпадение) и
  **плановая закупка/тендер** (решают ТЗ, гарантия, документация). **[ГИПОТЕЗА по приоритизации]**.
- Контент под запросы «аналог SEW/NORD…», «подбор», «передаточное число», «ремонт …редуктора» —
  подтверждённо востребован в нише **[ФАКТ]**; согласуется с блогом/гостевыми статьями Завода.
