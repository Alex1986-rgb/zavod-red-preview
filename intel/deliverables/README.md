# deliverables/ — итоговые материалы (Stage 3)

Заполняется командой `/intel-stage3`:
- `marketing-strategy.md` — маркетинговая стратегия.
- `site-brief.md` — бриф на редизайн/доработку сайта под конверсию.
- `smm-strategy.md` — SMM/контент-стратегия.
- `banners.md` — тексты баннеров (потом дизайн в Pencil).

Всё — `.md`, поэтому в боевой `dist/` не попадает (build-dist исключает `*.md`).
