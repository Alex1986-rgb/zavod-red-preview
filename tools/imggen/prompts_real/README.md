# `gearbox_real.txt` — параметризуемый фото-промпт под gpt-image-2

Экспериментальный файл. Ничего в `photo_card.py` / `oneshot.py` не тронуто — подключать вручную.

## Плейсхолдеры (ровно 5)

| Плейсхолдер | Источник | Пример подстановки | Место в шаблоне |
|---|---|---|---|
| `{{GEO}}` | `oneshot.GEO[gear]`, дефолт `GEO["червячный"]` | `a compact square worm gearbox with a finned electric motor, the output shaft at a 90 degree right angle to the motor` | блок 1: «The subject is {{GEO}}.» — все значения словаря начинаются с `a`/`an`, грамматика сходится |
| `{{STYLE}}` | `oneshot.BRAND_STYLE[brand]`, дефолт `DEFAULT_STYLE` | `Motovario style, BLUE painted cast housing` | блок 8: «Finish and colour: {{STYLE}}, a semi-matte industrial coat…» |
| `{{POWER}}` | `card["power"]` | `1,5` | блок 1: «sized for {{POWER}} kW input power» |
| `{{RATIO}}` | `card["ratio"]` | `7,5–100` | блок 1: «gear ratio range {{RATIO}}» |
| `{{MOUNT}}` | `oneshot.MOUNT[gear]`, дефолт `B3 / B5` | `B3 / B5 / B14` | блок 1: «built in {{MOUNT}} mounting configuration» |

Подстановка — обычный `str.replace`, без f-строк:

```python
from pathlib import Path
import oneshot as O

TPL = Path(__file__).with_name("prompts_real") / "gearbox_real.txt"

def build_prompt(card):
    g = card["gear"]
    return (TPL.read_text(encoding="utf-8")
            .replace("{{GEO}}",   O.GEO.get(g, O.GEO["червячный"]))
            .replace("{{STYLE}}", O.BRAND_STYLE.get(card["brand"], O.DEFAULT_STYLE))
            .replace("{{POWER}}", card["power"])
            .replace("{{RATIO}}", card["ratio"])
            .replace("{{MOUNT}}", O.MOUNT.get(g, "B3 / B5")))
```

Две оговорки по подстановке:

- `BRAND_STYLE` содержит имя бренда текстом (`"Motovario style, …"`). На картинку оно не выводится (в шаблоне прямой запрет на текст, логотипы и эмблемы), но если хочется полностью убрать даже упоминание — отрезать префикс до первой запятой и подставлять только цветовую часть: `style.split(", ", 1)[-1]`.
- `MOUNT` для двух типов передачи содержит русские значения (`Полый вал / лапы`, `Фланцевое`). Для англоязычного промпта разумнее подставлять `hollow shaft / foot` и `flange`, но это правится на стороне вызова, словарь в проде не меняем.

## Чем отличается от текущего промпта в `photo_card.py:70-95`

Текущий — один абзац ~700 знаков: `Photorealistic 8K … Cast iron housing … Pure white seamless studio background … a large BLANK polished steel nameplate`.

1. **Фото вместо рендера.** Убраны `Photorealistic 8K`, `ultra realistic textures`, `extremely sharp focus` — стек рендер-жаргона, который тянет картинку в CGI. Вместо него — реальные съёмочные параметры (полный кадр, 85 мм, f/11, ISO 200, штатив, 1.2 м) и явное «это фотография физического предмета».
2. **Материал не задан жёстко чугуном.** Было `Cast iron housing` для всех типов, включая алюминиевые червячные NMRV. Стало — материал следует из `{{GEO}}` и `{{STYLE}}`, а описываются три *типа поверхности* (литьё под краской / голая механобработка / оцинкованный крепёж).
3. **Выходной узел прописан покомпонентно.** Было `precision machined output shaft with keyway, round bolted output flange`. Стало — отдельный блок: центрирующий бурт, ровно 4 сквозных отверстия на одной окружности с фаской и перемычкой не меньше диаметра, шпоночный паз, видимый в расточке, манжета заподлицо, запрет открытого подшипника, транспортная заглушка сбоку от паза.
4. **Шильдик убран.** Было `a large BLANK polished steel nameplate` — пустая табличка читается как брак и провоцирует псевдотекст. Стало «плоская обработанная площадка без таблички», брендинг и так допечатывается офлайн в `brand()`.
5. **Рым-болты убраны.** Было `lifting eye bolts` для всех позиций, включая 10-килограммовые NMRV.
6. **Пропорции заданы сравнением, а не цифрами.** Модель игнорирует «кВт» и «кг»; работает «диаметр станины ≈ 0.75 высоты корпуса», «длина мотора ≈ 1.6 ширины корпуса», «кожух ≈ 1/4 длины мотора».
7. **Фон и свет.** Было `Pure white seamless studio background, subtle soft shadow` — прямой путь к «плавающему» объекту. Стало: серый верстак, окно слева + отражатель справа, жёсткая контактная тень под каждой лапой + вторая тень под свисающим мотором.
8. **Структура.** 11 нумерованных блоков вместо одного абзаца — критичные требования (шпонка, манжета, решётка кожуха) больше не тонут в середине длинного предложения.
9. **Финальный чек-лист внутри промпта** (блок 11) — 9 проверок, которые чаще всего разваливаются.
10. **Негативы переписаны в позитив** там, где это возможно: не «без глухих отверстий», а «каждое отверстие открытое, с фаской и видимой глубиной». Хвост-запрет оставлен коротким — gpt-image-2 не поддерживает negative prompt, длинный список запретов работает хуже утверждений.

## Какие правки судей учтены

- Выходной фланец: центрирующий бурт, ровно 4 сквозных отверстия на одной окружности, перемычка ≥ диаметра отверстия, фланец — часть отливки, а не приложенное кольцо (претензия №1 у всех четырёх судей).
- Шпоночный паз в расточке — прописан позитивно и с требованием «виден», заглушка сдвинута, чтобы не перекрывала паз.
- Манжета заподлицо в расточке + прямой запрет открытого шарикоподшипника на торце.
- Запрет зеркальности: противоположная грань описана иначе (плоский боббышка с меньшей расточкой и красной пробкой).
- Стык с двигателем: фланец B5 без лап, 4 болта на одной окружности, головки с одной стороны, центрирующий бурт, тонкая линия разъёма без зазора, адаптер отдельно привинчен к корпусу.
- Кожух вентилятора: не крупнее станины, решётка на ЗАДНЕМ торце, видна толщина листа и крыльчатка за прорезями, бобышка подшипникового щита между рёбрами и кожухом.
- Клеммная коробка: 4 винта по углам, прокладка по периметру, кабельный ввод в стенку самой коробки с контргайкой, заглушка на противоположном вводе, винт заземления.
- Три пробки: сапун с закрытым колпачком сверху, уровень сбоку, слив в нижней точке, каждая на своей обработанной бобышке с прерванными рёбрами; ни одного открытого штуцера.
- Крепёж: одинаковый в пределах стыка, читаемый привод, только на плоских обработанных площадках, каждый проходит сквозь деталь.
- Лапы: сквозные нерезьбовые отверстия, обработанные площадки, все четыре в одной плоскости и касаются верстака.
- Литейная культура: уклоны, радиусы у оснований рёбер, линия разъёма формы, следы толкателей; ни одно ребро не обрывается в воздухе.
- Свет и тень: один источник, одинаковое направление на всех узлах, контактная тень под каждой лапой + тень под мотором.
- Оптика реальности: зерно, виньетирование, лёгкая хроматика по углам.
- Микродефекты названы с местом и размером (скол 2 мм на верхнем переднем углу, пыль в трёх карманах, отпечаток в масляной плёнке) вместо абстрактного «wear».
- Полностью запрещены надписи, рельефные литые знаки и логотипы; шильдика нет.

## Ограничения, которые соблюдены

- **Сцена нулевой стоимости**: верстак + стена, ноль дополнительных предметов, ноль бумажных документов, ноль объектов с мелким узором. Это ровно тот бюджет, при котором `router.cheap` не отдаёт 524 (сравнение `gearbox_catalog_master` 9 объектов → таймаут vs `lite` → проходит).
- Длина ~7 КБ, но вся она — энумерация фич **одной связной геометрии**. По наблюдениям из разбора промптов router-gen дорого обходятся объекты сцены, а не токены описания одного корпуса. Если всё-таки ловится 524 — резать блоки 5 и 9, они наименее критичны для инженерной приёмки.
- Ни логотипов, ни читаемого текста, ни водяных знаков; фон нейтральный индустриальный; верхний правый угол просят держать спокойным под офлайн-оверлей ZR.

## Что промптом не лечится

Точное число болтов и рёбер, геометрия конкретного типоразмера и читаемый шильдик текстовым промптом не удерживаются. Для этих трёх вещей нужен пайплайн: img2img / reference от реального фото или от габаритного рендера из STP-каталога с силой денойза 0.3–0.45, и вклейка настоящего шильдика постобработкой.

## Сценовый вариант: `gearbox_real_scene.txt`

То же самое плюс два отличия, чтобы фото годилось под полную каталожную карточку `card.py`:

1. **Композиция под панель.** Изделие смещено в ПРАВУЮ половину кадра выходным концом влево,
   левая треть намеренно пустая (стена + столешница) — туда `card.py` кладёт белую панель с таблицей.
   Без этого таблица перекрывает товар.
2. **Сцена.** Позади справа один деревянный ящик из светлой сосны со стальными уголками,
   крышка закрыта, БЕЗ трафаретов и надписей. Больше в кадре ничего: ни бумаг, ни сертификатов,
   ни буклетов, ни флагов — их рисует `card.py` векторно, а не нейросеть.

### Полная карточка одной цепочкой

```bash
cd tools/imggen
# 1) фото со сценой
python3 - <<'PY'
import sys, os; sys.path.insert(0,'.'); sys.path.insert(0, os.path.expanduser('~/projects/router-gen'))
import oneshot as O, rgen
tpl = open('prompts_real/gearbox_real_scene.txt', encoding='utf-8').read()
c = dict(O.all_cards())['motovario-nmrv-050']; g = c['gear']
p = (tpl.replace('{{GEO}}',   O.GEO.get(g, O.GEO['червячный']))
        .replace('{{STYLE}}', O.BRAND_STYLE.get(c['brand'], O.DEFAULT_STYLE))
        .replace('{{POWER}}', c['power']).replace('{{RATIO}}', c['ratio'])
        .replace('{{MOUNT}}', O.MOUNT.get(g, 'B3 / B5')))
rgen.generate_image(p, out='gen/scene.png', size='1536x1024')
PY
# 2) таблица + логотипы + знаки + флаг + водяной знак
python3 card.py --model motovario-nmrv-050 --photo gen/scene.png --out gen/card.jpg
```

Разделение труда осталось прежним и оно принципиально: **нейросеть рисует только предмет и сцену,
весь текст впечатывает Pillow**. Когда таблицу пробовали рисовать промптом (`oneshot_router.py`),
мелкая кириллица искажалась — «ПРОМЫШЛЕННЫЕ РЕДХТОРЫ» на обложке буклета.
