Подбор редуктора по выходным оборотам

Подбор по оборотам — метод выбора редуктора, при котором по входным оборотам двигателя и требуемым выходным оборотам определяют нужное передаточное число (i=n1/n2) и подбирают ближайшее стандартное значение.

Подбор по оборотам отвечает на вопрос «как получить нужную скорость на выходе». Двигатель вращается быстро (обычно около 1500 об/мин), а механизму нужны десятки или единицы оборотов в минуту. Отношение этих скоростей и есть передаточное число, которое должен обеспечить редуктор. Это второй ключевой критерий подбора наряду с моментом.

Суть подбора по оборотам

Редуктор понижает быстрые обороты двигателя до медленных оборотов рабочего органа. Подбор по оборотам означает: зная входную скорость n1 (обороты двигателя) и требуемую выходную n2, вычислить нужное передаточное число и выбрать редуктор с ближайшим стандартным значением. Момент при этом растёт во столько же раз, во сколько падают обороты.

Формула передаточного числа

Передаточное число — отношение входных оборотов к выходным:

i = n1 / n2, где n1 — обороты двигателя (об/мин), n2 — требуемые обороты выходного вала (об/мин).

Например, при двигателе 1440 об/мин и требуемых 45 об/мин на выходе: i = 1440 / 45 = 32. Ближайшее стандартное передаточное число (например, 31,5 или 32) даст реальную выходную скорость n2 = n1 / iстанд.

Передаточные числа стандартизованы рядами (например, 5; 6,3; 8; 10; 12,5; 16; 20; 25; 31,5; 40; 50; 63; 80; 100…). Точно попасть в желаемую скорость удаётся редко, поэтому выбирают ближайшее значение и пересчитывают фактические обороты. Допустимое отклонение согласуют с технологией.

Порядок действий

  1. Определить обороты двигателя n1 (номинальные, с учётом скольжения, например 1440);
  2. Задать требуемые выходные обороты n2 из технологии;
  3. Вычислить желаемое передаточное число i = n1 / n2;
  4. Выбрать ближайшее стандартное передаточное число из ряда серии;
  5. Пересчитать фактическую выходную скорость и проверить допуск.

Подбор по оборотам всегда идёт в связке с проверкой момента: выбранный типоразмер должен выдержать нагрузку. Выполнить оба расчёта сразу удобно в калькуляторе подбора, а серии с разными передаточными числами — в каталоге редукторов большого передаточного и общем каталоге.

Связь со смежными терминами

  • Передаточное число — результат расчёта по оборотам;
  • Синхронные / номинальные обороты — задают входную скорость n1;
  • Крутящий момент — растёт пропорционально передаточному числу;
  • Подбор по моменту — параллельный критерий выбора типоразмера.

Вопросы и ответы

Частые вопросы

Как подобрать редуктор по оборотам?

Определите обороты двигателя (например 1440 об/мин) и требуемые выходные обороты. Разделите первое на второе — получите желаемое передаточное число i = n1/n2. Выберите ближайшее стандартное значение из ряда и пересчитайте фактическую выходную скорость n2 = n1/i.

Как рассчитать передаточное число?

По формуле i = n1/n2, где n1 — входные обороты (двигателя), n2 — требуемые выходные. Например, 1440/45 = 32. Точно в желаемую скорость попасть удаётся редко, поэтому берут ближайшее стандартное передаточное число из ряда серии редуктора.

Какие обороты двигателя брать для расчёта?

Реальные (номинальные) обороты с шильдика, учитывающие скольжение, например 1440 вместо синхронных 1500. Это даёт более точную выходную скорость. Для 4-полюсного двигателя обычно берут около 1400–1450 об/мин в зависимости от модели.

Почему выходная скорость отличается от желаемой?

Потому что передаточные числа стандартизованы дискретным рядом (25; 31,5; 40; 50…), и точно попасть в нужную скорость обычно нельзя. Выбирают ближайшее значение, а фактическую скорость пересчитывают: n2 = n1/i_станд. Отклонение согласуют с требованиями технологии.

Связан ли подбор по оборотам с моментом?

Да, они дополняют друг друга. По оборотам находят передаточное число, а по моменту — типоразмер. При понижении оборотов момент растёт пропорционально передаточному числу. Выбранный редуктор должен одновременно давать нужную скорость и выдерживать момент нагрузки.

Подбор редуктора по оборотам — определение передаточного числа по входным оборотам двигателя и требуемым выходным (i = n1/n2) с выбором ближайшего стандартного значения. Это второй ключевой критерий подбора наряду с моментом.
