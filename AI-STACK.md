# AI-стек проекта (внедрён из разбора видео «5 инструментов Claude Code»)

Этот файл — единая памятка по AI-инструментам, доступным в проекте. Общие знания вынесены в **глобальные скиллы** (`~/.claude/skills`), поэтому работают во всех проектах сразу.

## 1. Скиллы разработки (Matt Pocock, глобально)
Полный цикл: `/grill-with-docs` (агент добивает ТЗ вопросами) → `/to-spec` → `/to-tickets` → `/implement` → `/code-review`.
Плюс: `/tdd`, `/diagnosing-bugs`, `/research`, `/domain-modeling`, `/codebase-design`, `/wayfinder`, `/triage`.
Принцип: большую задачу дроби на тикеты, каждый — в чистом контексте.

## 2. Память проекта — LLM Wiki (глобальный скилл `llm-wiki`)
Структура `wiki/`: `index.md` (оглавление) + `entities/` (факты) + `concepts/` (выводы) + `log.md`.
Агент читает индекс, затем только нужные листы. Граф связей `[[...]]` смотреть в Obsidian.

## 3. Мультиагентные системы (глобальный скилл `agentic-system`)
Субагенты → `.claude/agents/`, оркестраторы → `.claude/commands/` (`/stage1`, `/stage2`, `/stage3`).
Стадии: аналитика → синтез → стратегия. Fan-out субагентов, гигиена контекста.

## 4. Внешние инструменты — Firecrawl + Exa (MCP)  ⚠️ требуется твой API-ключ
- **Exa Search** — веб-поиск для агентов (искать конкурентов).
- **Firecrawl** — парсинг сайтов в чистый Markdown.
Установка:
```bash
export FIRECRAWL_API_KEY=...   # ключ с firecrawl.dev
export EXA_API_KEY=...         # ключ с exa.ai
cp .mcp.json.example .mcp.json # активировать в проекте
```
После установки — **вписать инструмент в инструкции нужных агентов**, иначе не заработает.

## 5. Pencil — дизайн из Claude Code  ⚠️ desktop-приложение, ставится вручную
Бесплатно, `pencil.dev` (Desktop + VS Code extension + MCP). Подключается к твоей подписке Claude Code.
Генерирует баннеры/дизайн параллельными агентами. Ставится тобой отдельно (это не код).
