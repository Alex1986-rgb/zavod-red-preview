# Канон контента zavod-red.ru

## Эталоны (НЕ редактировать, только копировать структуру)
- Статья блога: `blog/kak-podobrat-reduktor.html`, `blog/raschet-peredatochnogo-chisla.html`
- Термин глоссария: `glossary/azotirovanie-zubev.html`
- Скелет для генерации (шапка/подвал/стили): `blog/analogi-bonfiglioli.html`

## Обязательные элементы статьи блога
1. `<title>` ≤ 70 знаков с ключевым запросом; `description` 140–165 знаков.
2. `canonical` + `og:url/title/description/image` — URL без `.html`.
3. **Три JSON-LD**: Article, BreadcrumbList, FAQPage (FAQ в разметке = FAQ на странице).
4. Hero: `eyebrow` (рубрика) → `<h1>` → `art-meta` («Опыт инженеров … ~N минут»).
5. Лид-абзац `lead-p`, затем 6–10 `<h2>` (пошаговые «Шаг 1…» где уместно).
6. **2–4 таблицы** `class="xref"` (соответствия серий, характеристики, чек-листы).
7. **Минимум 2 фото** `figure.art-fig` с alt и figcaption:
   - каталожное по типу: `../assets/catalog/cat_{worm|coaxial|bevel|flat|cylindrical}.webp`
   - производство: `../assets/production/p01.webp` (есть p01–p20)
8. Блок-чек-лист «Какие данные собрать перед заказом» (таблица параметр → где взять).
9. Разделы «Доставка, оплата и гарантия» и «Вывод» ближе к концу.
10. `note`-блок CTA: шильдик на zr@zavod-red.ru / онлайн-подбор.
11. **FAQ: 6–7 `<details>`** внутри `faq-grid > cat-faq`.
12. Перелинковка: `/podbor` (калькулятор — упоминать диапазоны, CSV, марки),
    `/catalog/<тип>`, `/brands/<бренд>`, `/ceny`, `/importozameshchenie`.
13. Объём: **не менее 500 слов** в теле статьи (среднее по блогу ~1000).

## Обязательные элементы термина глоссария
H2-структура: «Что такое X» → «Параметры и типовые значения» (таблица) →
«Отличие от Y» → «Влияние на подбор и эксплуатацию» → «Связь со смежными
терминами» (ссылки на другие термины) → «Частые вопросы» (5 details) →
партнёрский блок «Инженерам и проектировщикам — 5% с заказа».
4 JSON-LD (как в эталоне), 2 таблицы, перелинковка на глоссарий и каталог.

## Брендинг (ЖЁСТКО)
- Наша марка — **ZR** («Завод Редукторов», Челябинск). Обозначение **EVL запрещено**
  в любых видимых текстах, плейсхолдерах и таблицах (ребрендинг завершён).
  Допустимо только в данных калькулятора (ZRMAP в podbor.js) — не трогать.
- ГОСТ-серии (Ч, Ц2У, РМ, РЦД, МЧ) и NMRV упоминаем как наши/совместимые.
- Тон: инженерный, без маркетингового пафоса; честно про оригинал vs аналог
  («советуем честно: зарабатываем на обоих»).

## Массовая генерация — только генераторами
- `tools/gen_brand_articles.py` — 10 тем × бренды из `/brands/*.html` + общие ВЧ-темы.
- `tools/gen_type_articles.py` — 23 темы × 5 типов редукторов.
- Флаги: `--dry-run` (посчитать), `--rebuild` (перезаписать СВОИ статьи).
- `run_generator()` сам обогащает статьи до эталона (`enrich()`: фото, чек-лист,
  доставка, вывод, FAQ→6), обновляет `blog/index.html` и `sitemap.xml`
  только для новых слагов.
- **PROTECTED** в gen_brand_articles.py — слаги статей, существовавших до
  генераторов (они в топе выдачи): НИКОГДА не перезаписывать, список только пополнять.
- Новые единичные статьи: добавить тему в генератор (не писать HTML руками) —
  так шаблон гарантирован.

## Полный цикл публикации
```bash
python3 tools/gen_brand_articles.py --dry-run        # 1. прикинуть
python3 tools/gen_brand_articles.py                  # 2. сгенерировать
# 3. проверить целостность (обязательно):
#    title==1, canonical, 3 ld+json, faq-grid, details>=6, /podbor, </html>, слов>=500
git add blog/ sitemap.xml tools/ && git commit && git push origin main
gh workflow run deploy-site-lftp.yml --repo Alex1986-rgb/zavod-red-preview   # 4. деплой
# 5. дождаться success, проверить 3-5 URL на проде (curl → 200)
gh workflow run index-accelerator --repo Alex1986-rgb/zavod-red-preview      # 6. индексация
# IndexNow мгновенно уведомит Яндекс+Bing; переобход добавит ночной запуск
```
Сетевые сбои gh (TLS handshake timeout) — временные, повторить команду.

## Проверка после публикации
- `curl -s -o /dev/null -w '%{http_code}' https://zavod-red.ru/blog/<slug>` → 200
- Лог индексации: `gh run view <id> --log | grep IndexNow` → HTTP 200/202
- Прогресс в поиске: Webmaster API `searchable_pages_count` (токен в
  `~/.config/zavod/yandex_webmaster_token`)
