# Pro-карточка /analog/ — стандарт (эталон siti-bh-140)

## Генератор
`tools/analog_card_pro.py` — превращает a2-карточку /analog/ в pro-карточку.
- `python3 tools/analog_card_pro.py analog/{файл}.html` — одна страница
- `python3 tools/analog_card_pro.py --all` — все /analog/*.html (идемпотентно:
  страницы с маркером `<!--apro-->` пропускаются)
- Читает данные из a2-карточки (h1, таблица th/td, eyebrow, em-строку h1).
  Спеки извлекаются гибко: «Мощность»/«Мощность двигателя», «Момент»/«Крутящий
  момент» и т.п., фолбэк — из `<em>X кВт · Y Н·м · i=Z</em>`.

## Структура (сверху вниз)
1. **hero** (2 колонки, галерея sticky на десктопе):
   - слева: главное фото + 4 миниатюры (2 ракурса бренда + категория + чертёж)
     + `.p2-note-dw` + тех.документация (`.p2-docs`);
   - справа: eyebrow «Импортозамещение · {тип}» → h1 «{модель} — мотор-редуктор
     и российский аналог {ZR}» → цена/наличие → оффер-плашка → строки
     Бренд/Модель/Наш аналог/Категория → 3 кнопки в ряд (`.p2-cta1`) →
     4 плитки преимуществ (`.p2-trust`). Колонки балансируются (~700/700).
2. **`.apro-nav`** (липкая): Описание · Характеристики · Вопросы · [Получить расчёт].
3. **#opis** «Описание» — ПОДРОБНОЕ SEO-описание (видимое): 3–6 абзацев с
   ПЕРЕЛИНКОВКОЙ (/reduktor/{ZR}, /brands/{slug}, /podbor, /importozameshchenie,
   /catalog/) + 4 карточки `.why-grid`.
4. **#spec** «Характеристики» — 2 колонки: таблица характеристик + применения.
5. **#faq** — 8 вопросов в 2 блока по 4 (`.faq2`).
6. **#seo** — deep-хвост под стрелкой (`.seo-more`): доп. абзацы + таблица
   соответствия + перелинковка.
7. **`.p2-band`** — тёмная финальная CTA-полоса.

## Фото — по фирме (обязательно)
`brand_photos(imp_short)` подбирает `assets/catalog/br-{slug}-t*.webp` по бренду
(SEW→br-sew, NORD→br-nord, SITI→br-siti, Watt→br-watt-drive и т.д.). Если фото
бренда нет — категорийное `cat_{тип}.webp`. Все 73 785 страниц имеют фото фирмы.
Новые бренд-фото класть как `assets/catalog/br-{slug}-t0.webp` (и -t1).

## Персональный копирайт (override)
`tools/analog_copy/{slug}.json` — премиум-текст для конкретной страницы
(поля: opis_paragraphs, applications, why_analog, seo_deep_paragraphs,
meta_title, meta_description). Абзацы хранят HTML как сущности (`&lt;b&gt;`) —
генератор разворачивает. Нет override → качественный ШАБЛОННЫЙ текст с
перелинковкой (параметризован по модели/бренду/типу). Премиум-копирайт для
топ-страниц удобно генерировать мультиагентным Workflow (3 копирайтера разных
углов + SEO-семантика → синтез), результат сохранять в analog_copy/{slug}.json.

## Правила
- Никаких дублей: таблица характеристик — одна (в #spec), не повторять в hero.
- Слово «аналог» уместно (это страница аналога); «оригинал/аналог» как бейдж — нет.
- Класс CTA-полосы — `.p2-band` (не `cta-band`, конфликт со светлой темой).
- Мобайл: галерея не sticky, кнопки в столбец, гриды в 1 колонку.

## Деплой
Ручной `deploy-analog-lftp.yml` (73k файлов, ~40 мин). Порядок регенерации
при перезапуске конвейера: analog_twocard → analog_docs → analog_origbtn →
analog_card → **analog_card_pro**. Грабли lftp/очереди — см. [[zavod-analog-twocard]].
