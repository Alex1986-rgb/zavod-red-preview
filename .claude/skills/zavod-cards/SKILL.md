# Карточки товара zavod-red.ru — единый стандарт

## Эталон
`reduktor/evl-063-747.html` (ZR 606/604) — все карточки товара `/reduktor/*.html`
имеют этот тип. Проверка соответствия: в файле есть маркер `<!--p2b-->`.

## Структура карточки (порядок блоков, сверху вниз)
1. **hero** (`.p2`): галерея (фото типа + миниатюра чертежа, переключаются) +
   инфо: h1 «Редуктор ZR N {тип} промышленный» (БЕЗ «обозначение EVL»),
   «Цена по запросу» + бейдж «В наличии / под заказ», строки Производитель /
   Код товара (**только ZR**, без «(EVL …)») / Категория, 4 бейджа-преимущества,
   описание, таблица характеристик, CTA «Запросить цену» / «Подобрать аналог»,
   блок **Техническая документация** (Расшифровка маркировки ZR /markirovka-zr,
   Монтажные положения /glossary/montazhnoe-polozhenie, Характеристики #spec).
2. **липкая навигация** (`nav.pc-nav`): Характеристики · Типоразмеры · Заменяет
   импорт · Описание · Вопросы + красная «Получить расчёт».
3. **#spec** Характеристики → **#tz** Типоразмеры → **#analogi** «Заменяет
   импортные приводы» (чипы брендов → /analog/{u}, ссылка на бренд второй, мелкой) →
   4 плитки преимуществ (`.pc-adv`) → **#opis** Описание → **#faq** → Похожие
   модели → тёмная CTA-полоса `.p2-band` → SEO-текст.

## Правила
- **Код товара — только ZR** (никаких «(EVL …)», «обозначение EVL» в видимом тексте).
  URL-слаги остаются `evl-*` (редиректы zr→evl в .htaccess), но пользователю — ZR.
- **Главное правило (решение заказчика 20.07.2026, отменяет прежний «единый тип карточки»):**
  если у позиции есть импортный бренд — карточка принадлежит ИМПОРТУ. Бренд и модель
  крупно и жирно, наш аналог ZR — мелкой вторичной строкой. Пришёл по бренду — видишь бренд.
  Прежний канон вёл все плитки на обезличенную `/reduktor/`, и клик по «SEW F 107» открывал
  «Редуктор ZR 6106» без единого упоминания SEW. Это признано багом, не фичей.
- **Плитки каталога и брендов** (`.pcard`): порядок приоритета жёсткий —
  `url = c.u ? '/analog/'+c.u : (c.r ? '/reduktor/'+c.r+'?imp='+encodeURIComponent(b+' '+m)
  : '/podbor?q='+…)`. Сначала карточка импорта, и только если её нет — наша карточка ZR,
  но обязательно с `?imp=`, иначе бренд теряется. Плитки без импортного бренда
  (планетарные 3МП/МР/МПО) ведут на `/reduktor/` или `/podbor` как раньше.
- **Параметр `?imp=Бренд Модель`** читают все 117 `/reduktor/*.html` (маркер `ZR_IMPCTX`
  перед `</body>`): H1, `<title>` и крошки перестраиваются под бренд — бренд 24px/800,
  «наш аналог ZR …» 14px/500. Нужен для 120 из 498 позиций, у которых нет слага `u`
  (Vemper, Tramec, Watt Drive, Innored, Tos Znojmo, часть Varvel, Varmec, STM).
- **Чипы «Заменяет импортные приводы»** ведут на `/analog/{u}`, а ссылка на страницу
  бренда — вторая и мелкая. Раньше чип вёл на `/brands/{slug}` и получалась петля:
  бренд → карточка ZR → чип → снова бренд, а страница аналога была недостижима.
- **Карточка /analog/ — две кнопки, не три:** «Запросить оригинал» красной и первой
  (карточка принадлежит импорту), «Подобрать аналог» белой и второй. У каждой свой
  `data-req` — он уходит в тело заявки, менеджер видит, что именно просили.
  Скрипт `tools/analog_cta_two.py`, идемпотентен.
- **Кнопка «Заказать» в таблице подбора** ведёт на `/analog/`, а не на карточку ZR.
  Слаг НЕ склеивать из чисел: в именах файлов передаточные целые, в базе подбора дробные,
  разделитель то дефис, то подчёркивание, у дублей суффикс. Берётся ближайшая реальная
  страница из `assets/analog-idx/<бренд>.json` (генератор `tools/gen_analog_index.py`).
- **Проверка перед деплоем:** `python3 tools/check_site.py --dist` — 12 инвариантов этого
  канона. Падает, если перегенерация что-то откатила.
- **Класс CTA-полосы — `p2-band`**, НЕ `cta-band` (последний конфликтует со
  светлой темой в inner.css — полоса выцветает).

## Скрипты (репо, идемпотентны)
- `tools/reduktor_card.py --all` — базовый hero карточки (галерея, цена, таблица).
- `tools/reduktor_card2.py --all` — структура (навигация, #analogi, преимущества,
  p2-band). Порядок: `reduktor_card.py` → `reduktor_card2.py`.
- `tools/catalog_tiles.py --all` — плитки каталога.
- `tools/catalog_tiles_analog.py` — перевод плиток категорий на /analog/{u}.
- `tools/reduktor_chips_analog.py` — чипы «Заменяет импорт» на /analog/{u}.
- `tools/gen_search_index.py` — индекс поиска из import-catalog.json (со слагами u и r).
- Карта ZR→слаг строится из reduktor-страниц по строке «Код товара / Модель: ZR N».

## Деплой
Обычный `deploy-site-lftp.yml` (авто по push). Проверять прод curl-ом. Грабли —
см. память [[zavod-analog-twocard]]: lftp сравнивает по размеру (правка одинаковой
длины не заливается → байт-маркер/бамп ?v=), очередь общая с параллельной сессией.
