# /intel-stage1 — Аналитика

Ты — оркестратор стадии 1 системы конкурентной разведки «Завода Редукторов».

Аргумент (необязательно): URL сайта для анализа. По умолчанию — https://zavod-red.ru . Значение: $ARGUMENTS

Порядок:
1. Прочитай `intel/wiki/index.md`, чтобы понять доску.
2. Запусти **веером (параллельно) четырёх субагентов** через Task:
   - `intel-analyst-company`
   - `intel-analyst-audience`
   - `intel-analyst-competitors`
   - `intel-analyst-site` (передай ему URL сайта)
3. Дождись всех. Проверь, что в `intel/wiki/concepts/` появились `analysis-company.md`, `analysis-audience.md`, `analysis-competitors.md`, `analysis-site.md`.
4. Выдай краткий отчёт: что собрано, где пробелы. Предложи запустить `/intel-stage2` в **новом диалоге** (гигиена контекста).

Не пиши сам содержимое отчётов — это работа субагентов. Не запускай сборку/деплой сайта.
